# حاسبة السعر العكسية — تابي وضريبة القيمة المضافة

تطبيق ويب تقدمي (PWA) يعمل دون إنترنت. تُدخل المبلغ الذي تريد أن يبقى لك (تكلفتك وربحك معًا)، فيعطيك سعر البيع الذي يجب عرضه.

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | التطبيق كاملًا (لا يعتمد على أي مكتبة خارجية) |
| `manifest.json` | بيانات التثبيت على الشاشة الرئيسية |
| `sw.js` | العمل دون إنترنت |
| `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` · `apple-touch-icon.png` | الأيقونات |

احتفظ بالملفات كلها في **نفس المجلد**، دون مجلدات فرعية.

## التشغيل محليًا

```bash
cd <مجلد الملفات>
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

فتح `index.html` بنقرة مزدوجة يعمل أيضًا، لكن `file://` يمنع تسجيل الـ service worker، فلا يعمل وضع «دون إنترنت» ولا يظهر زر التثبيت. الحساب نفسه يعمل في الحالتين.

## النشر

ارفع المجلد كما هو إلى أي استضافة ثابتة تدعم HTTPS (GitHub Pages أو Netlify أو Cloudflare Pages أو مجلد على خادمك). التثبيت على الجوال يتطلب HTTPS.

- **أندرويد / كروم:** يظهر زر «تثبيت» في أعلى الصفحة، أو من قائمة المتصفح «إضافة إلى الشاشة الرئيسية».
- **آيفون / سفاري:** زر المشاركة ← «إضافة إلى الشاشة الرئيسية». (سفاري لا يدعم زر التثبيت البرمجي.)

## التحديث

بعد أي تعديل على `index.html`، غيّر رقم النسخة في أول سطر من `sw.js`:

```js
var CACHE = "reverse-price-v2";
```

وإلا بقيت النسخة القديمة مخزّنة على أجهزة من فتحوا التطبيق سابقًا.

## المعادلة

```
سعر البيع = (المبلغ المطلوب + الرسم الثابت) ÷ (1 − نسبة ضريبة المبيعات − نسبة تابي المتغيرة)
```

نسبة الضريبة على رسوم تابي لا تدخل في المعادلة: خصمها من ضريبة المبيعات يُلغيها تمامًا.
